# 简易防火墙课程设计报告

## 1. 选题背景与目标

网络安全是保障主机与网络服务正常运行的重要基础，防火墙是网络安全体系中最基础也最关键的一环。本课程设计选题为"简易防火墙设计"，目标是实现一个可在 Linux 环境下真实运行的防火墙管理系统，支持通过图形化界面完成规则配置、自定义规则语言解析、网络流量监控、日志审计以及运行结果的图表化动态展示。

系统面向单台 Linux 主机的入站/出站流量控制（对应 iptables 的 INPUT/OUTPUT 链），既满足题目对"实际网络环境测试"的要求，又保证演示环境的稳定与可控。

## 2. 需求分析

依据题目要求，系统需满足以下功能：

1. **界面**：提供 Web 图形界面，可配置规则、可显示系统运行结果。
2. **规则设置**：自行设计防火墙规则语言并实现解析器；规则至少涵盖 IP 地址、端口、传输协议；支持立即更新与定量更新（时间、数量两种）。
3. **运行结果**：对运行结果进行分析并以图表形式动态连续展示；记录日志并存入数据库。
4. **代码规范**：源程序含注释，每个函数写明作用、入口参数含义与返回值含义。
5. **文档**：提供功能目标分解表与课程设计报告。

## 3. 总体设计

系统采用前后端分离架构：

```
Vue3 Web 界面  →  Flask REST API  →  规则解析器 / iptables 适配器 / Scapy 抓包
                       ↓
                   SQLite 数据库
```

- **前端**：Vue3 + Vue Router + Axios + ECharts，包含首页概览、规则管理、抓包监控、日志审计、系统设置五个页面。
- **后端**：Python3 + Flask，提供 REST API，模块化拆分为解析器、仓储层、iptables 适配器、抓包服务、更新服务。
- **数据存储**：SQLite，保存规则、更新队列、流量日志、系统日志与配置。
- **防火墙执行**：将启用规则转换为 iptables 命令；默认 dry-run，Linux 上授权后执行真实拦截。
- **流量监控**：Scapy 捕获数据包，解析五元组、协议、长度，用于统计与图表。

## 4. 规则语言设计

规则语言采用一行一条的文本格式：

```txt
ACTION DIRECTION PROTOCOL FROM SRC_IP TO DST_IP [SPORT SRC_PORT DPORT DST_PORT]
```

字段包括动作（ALLOW/DENY）、方向（IN/OUT）、协议（TCP/UDP/ICMP/ANY）、源/目标 IP（IPv4/CIDR/ANY）、源/目标端口（端口/范围/ANY）。解析器 `RuleParser` 完成词法拆分、关键字校验、IP 与端口合法性校验，输出结构化 `FirewallRule` 对象。详见《规则语言说明》。

## 5. 数据库设计

数据库包含 5 张核心表：

| 表 | 作用 |
|---|---|
| `rules` | 结构化防火墙规则 |
| `rule_updates` | 待应用更新队列，支撑立即/时间/数量更新 |
| `traffic_logs` | Scapy 解析后的数据包与匹配记录 |
| `system_logs` | 服务运行与规则应用日志 |
| `settings` | 网卡、更新模式、间隔、阈值等配置 |

## 6. 核心模块实现

- **规则解析器** `rule_parser.py`：解析并校验 DSL，非法输入抛出 `RuleParserError`。
- **仓储层** `repositories.py`：封装规则、日志、设置、统计的数据库读写，连接均显式关闭。
- **iptables 适配器** `iptables_adapter.py`：将规则转换为 iptables 命令；`run()` 默认 dry-run，保证安全。
- **更新服务** `update_service.py`：按优先级应用启用规则，返回生成或执行的命令结果。
- **抓包服务** `sniffer_service.py`：`packet_to_record()` 将 Scapy 数据包转为日志记录；`SnifferService` 管理运行状态。
- **API 层** `api.py`：提供健康检查、规则 CRUD、解析、应用、统计、日志、设置、抓包控制等 REST 接口，对非法请求体统一返回 400。
- **前端页面**：首页用 ECharts 展示流量折线图与协议饼图并每 2 秒轮询刷新；其余页面完成规则管理、抓包控制、日志查询与系统设置。

## 7. 测试与结果分析

采用测试驱动开发（TDD），后端使用 pytest：

- **规则解析测试**：合法/非法 DSL、IP、端口校验。
- **iptables 命令测试**：验证生成命令与预期一致，并确认默认不执行真实命令。
- **API 集成测试**：规则创建/列表/解析、统计、日志、设置读写、应用接口默认 dry-run、非法 JSON 体返回 400。
- **抓包转换测试**：验证 TCP/UDP/ICMP 数据包字段提取。

前端通过 `npm run build` 验证可正常构建。Linux 环境下，经用户授权后可对一条出站 DNS 拦截规则做真实验证：规则生效时 `dig @8.8.8.8` 失败，删除后恢复。

## 8. 总结

本系统以简洁、模块化的工程实践实现了简易防火墙的核心功能，涵盖规则配置、自定义规则语言解析、立即/定量更新、流量监控、图表展示、日志审计与数据库存储，满足课程设计题目的全部要求。系统默认安全（dry-run），可在 Linux 主机授权后进行真实拦截测试，具备良好的可扩展性。
