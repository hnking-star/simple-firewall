# 规则语言说明

## 语法

规则采用一行一条的文本格式：

```txt
ACTION DIRECTION PROTOCOL FROM SRC_IP TO DST_IP [SPORT SRC_PORT DPORT DST_PORT]
```

- 完整形式为 11 个词（含端口子句）。
- 省略端口子句时为 7 个词，源/目标端口默认视为 `ANY`。

## 字段

| 字段 | 取值 | 说明 |
|---|---|---|
| ACTION | `ALLOW` / `DENY` | 放行或拦截 |
| DIRECTION | `IN` / `OUT` | 入站（iptables INPUT）或出站（OUTPUT） |
| PROTOCOL | `TCP` / `UDP` / `ICMP` / `ANY` | 传输协议 |
| SRC_IP | IPv4 / CIDR / `ANY` | 源地址 |
| DST_IP | IPv4 / CIDR / `ANY` | 目标地址 |
| SRC_PORT | 端口 / 端口范围 / `ANY` | 源端口，`ICMP` 可省略 |
| DST_PORT | 端口 / 端口范围 / `ANY` | 目标端口，`ICMP` 可省略 |

- 端口范围写作 `start-end`，转换为 iptables 时使用 `start:end`。
- 关键字大小写不敏感，解析后统一转为大写。

## 示例

```txt
DENY OUT UDP FROM ANY TO 8.8.8.8 SPORT ANY DPORT 53
ALLOW IN TCP FROM ANY TO ANY SPORT ANY DPORT 22
DENY IN ICMP FROM 10.0.0.5 TO ANY
ALLOW IN TCP FROM 192.168.1.0/24 TO ANY SPORT ANY DPORT 8000-9000
```

## 解析结果

解析器 `RuleParser.parse()` 输出结构化对象，例如：

```json
{
  "action": "DENY",
  "direction": "OUT",
  "protocol": "UDP",
  "src_ip": "ANY",
  "dst_ip": "8.8.8.8",
  "src_port": "ANY",
  "dst_port": "53"
}
```

## 校验规则

- 动作、方向、协议必须在允许集合内，否则报错。
- IP 必须为合法 IPv4 地址或 CIDR，或 `ANY`。
- 端口必须为 1-65535 的数字、合法端口范围，或 `ANY`。
- 词数必须为 7 或 11，`FROM` / `TO` / `SPORT` / `DPORT` 关键字位置必须正确。

非法规则会抛出 `RuleParserError`，API 层统一返回 400 JSON，前端展示中文错误提示。
