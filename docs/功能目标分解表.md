# 功能目标分解表

| 题目要求 | 系统功能 | 实现模块 |
|---|---|---|
| 界面可配置、可显示系统运行结果 | Web 管理界面、首页概览与图表 | `frontend/` Vue3 页面、`backend/app/api.py` |
| 自行设计规则语言并撰写解析器 | DSL 规则输入与解析、校验 | `backend/app/rule_parser.py` |
| 规则涉及 IP、端口、传输协议 | 规则字段覆盖动作/方向/协议/源目 IP/端口 | `rules` 表、`RuleParser`、`FirewallRule` |
| 立即更新 | 保存规则后立即应用 | `backend/app/update_service.py`、`iptables_adapter.py` |
| 时间定量更新 | 按设定间隔批量应用 | `settings` 表（update_interval）、`update_service.py` |
| 数量定量更新 | 累计变更达阈值后批量应用 | `settings` 表（update_batch_size）、`rule_updates` 表 |
| 运行结果分析、图表动态连续展示 | 流量折线图、协议分布饼图、计数卡片 | `frontend/src/pages/Dashboard.vue`、ECharts |
| 记录日志、分析 | 拦截/放行流量日志、系统运行日志 | `traffic_logs`、`system_logs` 表、`Logs.vue` |
| 运行结果存入数据库 | 规则、日志、配置持久化 | `backend/app/db.py`、`repositories.py`、SQLite |
| 代码注释、函数说明 | 每个函数含 docstring（作用/入参/返回值） | 后端全部模块 |
| 相关文档 | 功能目标分解表、规则语言说明、课程设计报告 | `docs/` |

## 模块职责说明

| 模块 | 职责 |
|---|---|
| `app/config.py` | 路径与默认配置 |
| `app/db.py` | SQLite 连接与表结构初始化 |
| `app/models.py` | `FirewallRule` 数据结构 |
| `app/rule_parser.py` | DSL 解析与校验 |
| `app/repositories.py` | 规则/日志/设置/统计的数据库读写 |
| `app/iptables_adapter.py` | 生成并执行 iptables 命令（默认 dry-run） |
| `app/update_service.py` | 立即/时间/数量更新逻辑，应用启用规则 |
| `app/sniffer_service.py` | Scapy 抓包状态与数据包字段转换 |
| `app/api.py` | REST API 路由 |
